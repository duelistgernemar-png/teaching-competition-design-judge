# Claude Entry Guide

Use this repository as an instruction-and-reference bundle for evaluating Chinese K-12 teaching-competition lesson designs.

Read `AGENTS.md` first, then `SKILL.md`, then the required files under `references/`.

Core rule: evaluate only the teaching-design evidence provided by the user. Do not score classroom recording performance, live teaching behavior, classroom management, or teaching reflection unless the user provides separate evidence and asks for a separate review.

Default output language: Chinese.
