# 教学比赛教学设计获奖样本通用亮点

Based on the locally classified corpus under `local classified winning-design corpus`.

## Cross-Subject High-Score Patterns

1. **Real problem context**
   - Strong designs start from a real phenomenon, case, task, text, data, artwork, movement problem, or social issue.
   - The context is not decoration; it creates the need for the lesson's core concept/method.

2. **Visible core problem**
   - Winning designs often have a central question that runs through the whole lesson.
   - The question chain shows cognitive progression rather than a list of teacher procedures.

3. **Student-generated outputs**
   - High-score designs make students produce something visible: model, diagram, argument, table, map analysis, explanation, plan, performance, written paragraph, experiment plan, etc.
   - These outputs become evidence for process evaluation.

4. **Teaching-learning-assessment consistency**
   - Objectives, activities, outputs, and evaluation criteria point to the same learning target.
   - Evaluation is embedded in activities rather than added at the end.

5. **Subject-specific thinking**
   - Biology: evidence reasoning and model construction.
   - Geography: map/data evidence, spatial scale, regional analysis.
   - Chinese: text evidence, language practice, reading-writing integration.
   - Mathematics: problem structure, representation transformation, reasoning.
   - English: thematic meaning, discourse analysis, language use.
   - PE/art/music: skill demonstration, practice progression, observation/evaluation criteria.

6. **Meaningful digital technology**
   - High-score technology use solves a learning difficulty: visualizes the invisible, supports comparison, captures performance, enables data analysis, or displays student thinking.
   - Low-score technology only plays media or decorates slides.

7. **Discipline-grounded course ideology**
   - Strong designs embed values into disciplinary tasks: scientific spirit, cultural confidence, national strategy, ecology, rule consciousness, responsibility, aesthetic cultivation.
   - Weak designs append value slogans after knowledge learning.

## Common Weaknesses To Flag

- Background analysis is long but not diagnostic.
- Objectives are grand but not measurable.
- Problem chain has no logical dependency.
- Activities are lively but lack disciplinary thinking.
- Student output is unclear.
- Evaluation lacks criteria.
- Digital technology is generic.
- Course ideology is detached from the lesson task.
