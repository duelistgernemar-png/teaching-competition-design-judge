# 小学心理健康教学设计深度模式

Sample strength: low, 3 local designs. Topics include anti-bullying language, listening, and understanding others.

## Winning Orientation

High-scoring primary psychology lessons create a safe experience where children notice feelings, name needs, practice a strategy, and plan a small action. The lesson must avoid exposing private trauma or judging students; it should use stories, games, role play, cards, drawing, and gentle sharing.

## Judge Focus

- Background analysis should describe the developmental issue and class safety needs.
- Objectives should include awareness, expression, strategy practice, and transfer.
- Core questions should be life-based: “怎样听见别人真正想说的话”, “玩笑为什么会伤人”.
- Activities should move from low-risk体验 to 分享觉察 to 方法练习 to 行动承诺.
- Evaluation should observe participation safety, strategy use, and reflection quality, not right/wrong answers.

## High-Score Evidence

Look for confidentiality rules, opt-out options, teacher language that protects students, scenario practice, and after-class application.

## Deduction Risks

扣分常见于心理课德育化说教、活动可能伤害学生、要求公开隐私、方法不可操作、缺少复盘。

## Revision Priority

Add safety agreement; lower disclosure risk; teach one clear strategy; use scenario transfer instead of personal exposure.

## 获奖作品画像强化模块

Sample level: C 低样本; local sample count: 3.

### Representative Topic Cluster

- 袁康茜-语中美好，不“欺”而遇——五年级心理
- 郑嘉宇-四年级心理健康课《超级小耳朵——发射倾听卫星》
- 梁琪-走近彼此的世界

### Discipline-Specific Scoring Differentiators

- 心理安全、体验觉察、策略练习和迁移应用是核心。
- 高分作品用低风险情境帮助学生认识自我、练习方法、形成行动计划。
- 扣分最敏感的是公开隐私、德育说教化、活动情绪风险过高。
- 评分时必须说明该教学设计的学生产出是什么，以及产出如何证明本学科核心素养达成。

### High-Score Structure To Look For

1. 从真实情境或学科现象提出核心问题。
2. 用递进问题链组织学生经历“感知/观察/阅读/体验 - 分析/探究/练习 - 表达/解释/创作/应用”。
3. 设置可见学生成果，并给出分层评价标准。
4. 支撑材料、数字技术和课程思政都服务本学科关键学习困难。

### Replacement Text Templates

Core question: 面对【心理/人际/成长情境】，我可以怎样觉察并调适？

Objective template: 学生能够基于【材料/现象/文本/任务】，运用心理健康的【关键方法】，完成【可见成果】，并说明【证据/理由/改进依据】。

Evaluation criterion template: 能否使用【本学科证据】支撑【解释/表达/作品/动作/方案】，标准分为“不能说明 - 能部分说明 - 能完整说明 - 能迁移或改进说明”。

Course-ideology template: 本课的价值引领应从心理健康学习过程自然生成，落在【尊重证据/审美判断/规则意识/文化理解/健康责任/数字伦理/公共参与】中的一个重点，避免泛化口号。
