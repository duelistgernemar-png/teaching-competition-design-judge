# 初中体育教学设计深度模式

Sample strength: low, 2 local designs. Topics include volleyball movement/passing and gymnastics shoulder-elbow stand/roll sequence.

## Winning Orientation

High-scoring junior PE designs emphasize skill refinement, fitness load, tactical/application context, safety, and student self-monitoring. Adolescents need clear technical standards, enough practice density, and differentiated challenge.

## Judge Focus

- Background analysis should identify movement foundation, physical difference, safety risk, and motivation.
- Objectives should include skill quality, fitness, cooperation/rules, and health behavior.
- Core question should name the technical problem: “怎样移动到位并稳定垫球”.
- Activities should include专项热身、技术分解、合作练习、组合应用、比赛/展示、放松评价.
- Evaluation should include movement criteria, success rate, cooperation, and safety behavior.

## High-Score Evidence

Look for safe protection, group rotation, clear load arrangement, peer observation sheets, and differentiated practice.

## Deduction Risks

扣分常见于安全保护不足、练习密度低、评价只看完成、技术要点不清、分层不足。

## Revision Priority

Define key movement indicators; add safety and organization map; specify load/practice density; include peer feedback criteria.

## 获奖作品画像强化模块

Sample level: C 低样本; local sample count: 2.

### Representative Topic Cluster

- 刘若楠-水平四初二排球滑步移动垫球
- 冯凯阳-七年级肩肘倒立-前滚成蹲立

### Discipline-Specific Scoring Differentiators

- 动作质量、练习密度、分层挑战、安全保护和表现评价是核心。
- 高分作品有清晰动作标准、组织路线、差异化练习和即时反馈。
- 扣分最敏感的是安全与负荷不清、游戏和技能目标脱节。
- 评分时必须说明该教学设计的学生产出是什么，以及产出如何证明本学科核心素养达成。

### High-Score Structure To Look For

1. 从真实情境或学科现象提出核心问题。
2. 用递进问题链组织学生经历“感知/观察/阅读/体验 - 分析/探究/练习 - 表达/解释/创作/应用”。
3. 设置可见学生成果，并给出分层评价标准。
4. 支撑材料、数字技术和课程思政都服务本学科关键学习困难。

### Replacement Text Templates

Core question: 怎样改进【关键动作/战术】以提升运动表现？

Objective template: 学生能够基于【材料/现象/文本/任务】，运用体育的【关键方法】，完成【可见成果】，并说明【证据/理由/改进依据】。

Evaluation criterion template: 能否使用【本学科证据】支撑【解释/表达/作品/动作/方案】，标准分为“不能说明 - 能部分说明 - 能完整说明 - 能迁移或改进说明”。

Course-ideology template: 本课的价值引领应从体育学习过程自然生成，落在【尊重证据/审美判断/规则意识/文化理解/健康责任/数字伦理/公共参与】中的一个重点，避免泛化口号。
