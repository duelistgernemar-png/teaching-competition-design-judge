## Sample-Strength Rule

Each deep pattern file states its local sample strength. Use high-sample files with more confidence. For low-sample files, treat the pattern as a cautious orientation and rely more heavily on the official rubric plus the uploaded teaching-design evidence.

## Cross-Discipline And Misclassification Rule

Some local folders contain cross-discipline or possibly misclassified items. Do not force the folder label onto a new upload. Identify 学段/学科 from title, grade, textbook, objectives, learning content, and activity evidence. When uncertain, state the uncertainty and use the nearest pattern conservatively.
