# 小学信息科技教学设计深度模式

Sample strength: medium-high, 15 local designs. Topics include data visualization, lists, control systems, smart home, visitor management, earthquake simulation, warm boxes, cars, interdisciplinary technology integration, and digital projects.

## Winning Orientation

High-scoring primary information technology designs use real tasks to cultivate computational thinking. The strongest lessons do not only teach software operations; they help students decompose a problem, represent data/processes, build or debug a digital work, and reflect on responsible use.

## Judge Focus

- Background analysis should identify students' tool familiarity and computational concept difficulty.
- Objectives should include decomposition, data representation, algorithm/process design, operation, debugging, and digital responsibility.
- Core questions should be task-based: “怎样让系统自动判断”, “数据怎样帮助决策”.
- Activities should move through需求分析、方案设计、操作实现、测试调试、展示改进.
- Evaluation should include functionality, logic, usability, debugging process, and teamwork.

## High-Score Evidence

Look for authentic campus/home/community scenarios, flowcharts, data tables, code or block logic, iteration records, and privacy/safety discussion.

## Deduction Risks

扣分常见于只照步骤操作、任务情境与信息科技概念脱节、作品无评价标准、没有调试、忽视数据安全与伦理。

## Revision Priority

Clarify the computational concept; add design-before-operation; require testing/debugging evidence; include digital ethics where relevant.

### Discipline-Specific Scoring Differentiators

- 计算思维、数据/算法/系统建模、实现调试和数字伦理是核心。
- 高分作品从真实任务出发，经历需求分析、方案设计、实现测试、迭代改进。
- 扣分最敏感的是工具步骤化、没有调试证据、忽视数据安全。
- 评分时必须说明该教学设计的学生产出是什么，以及产出如何证明本学科核心素养达成。

### High-Score Structure To Look For

1. 从真实情境或学科现象提出核心问题。
2. 用递进问题链组织学生经历“感知/观察/阅读/体验 - 分析/探究/练习 - 表达/解释/创作/应用”。
3. 设置可见学生成果，并给出分层评价标准。
4. 支撑材料、数字技术和课程思政都服务本学科关键学习困难。

### Replacement Text Templates

Core question: 怎样用【数据/算法/系统】解决【真实问题】？

Objective template: 学生能够基于【材料/现象/文本/任务】，运用信息科技的【关键方法】，完成【可见成果】，并说明【证据/理由/改进依据】。

Evaluation criterion template: 能否使用【本学科证据】支撑【解释/表达/作品/动作/方案】，标准分为“不能说明 - 能部分说明 - 能完整说明 - 能迁移或改进说明”。

Course-ideology template: 本课的价值引领应从信息科技学习过程自然生成，落在【尊重证据/审美判断/规则意识/文化理解/健康责任/数字伦理/公共参与】中的一个重点，避免泛化口号。
