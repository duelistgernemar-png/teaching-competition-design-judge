# 小学舞蹈教学设计深度模式

Sample strength: very low, 1 local design. Use this as cautious orientation and rely on the uploaded design evidence.

## Winning Orientation

High-scoring primary dance designs help children experience movement, rhythm, space, and emotion. A strong design moves from warm-up and body awareness to movement elements, phrase learning, expressive creation, and performance reflection.

## Judge Focus

- Background analysis should identify coordination, rhythm, posture, expression, and confidence needs.
- Objectives should include mastering selected movement elements, performing with rhythm, expressing an emotion/theme, and cooperating safely.
- Core questions should be expressive: “身体怎样表现不同情绪/形象”.
- Activities should include观察模仿、分解练习、组合连接、队形/空间调整、展示评价.
- Evaluation should include rhythm, posture, movement quality, expression, cooperation, and improvement.

## High-Score Evidence

Look for safe warm-up, movement vocabulary, music connection, visual demonstration, creative variation, and respectful performance feedback.

## Deduction Risks

扣分常见于只排动作不讲学习、忽视安全热身、评价只说整齐、缺少表达目标、低样本结论过度泛化。

## Revision Priority

Write the movement element and expression goal clearly; add layered practice; specify safety; create simple performance criteria.

## 获奖作品画像强化模块

Sample level: C 低样本; local sample count: 1.

### Representative Topic Cluster

- 张萱-教学反思视频

### Discipline-Specific Scoring Differentiators

- 身体元素、节奏空间、动作质量、表达和安全是核心。
- 高分作品有热身、分解、组合、创编和展示评价。
- 扣分最敏感的是只排动作不形成学习，评价只看整齐。
- 评分时必须说明该教学设计的学生产出是什么，以及产出如何证明本学科核心素养达成。

### High-Score Structure To Look For

1. 从真实情境或学科现象提出核心问题。
2. 用递进问题链组织学生经历“感知/观察/阅读/体验 - 分析/探究/练习 - 表达/解释/创作/应用”。
3. 设置可见学生成果，并给出分层评价标准。
4. 支撑材料、数字技术和课程思政都服务本学科关键学习困难。

### Replacement Text Templates

Core question: 怎样用身体动作表现【情绪/形象/主题】？

Objective template: 学生能够基于【材料/现象/文本/任务】，运用舞蹈的【关键方法】，完成【可见成果】，并说明【证据/理由/改进依据】。

Evaluation criterion template: 能否使用【本学科证据】支撑【解释/表达/作品/动作/方案】，标准分为“不能说明 - 能部分说明 - 能完整说明 - 能迁移或改进说明”。

Course-ideology template: 本课的价值引领应从舞蹈学习过程自然生成，落在【尊重证据/审美判断/规则意识/文化理解/健康责任/数字伦理/公共参与】中的一个重点，避免泛化口号。
